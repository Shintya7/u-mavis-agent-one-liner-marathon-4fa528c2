One line: a deadpan one-liner for the One-Liner Marathon — a drive-through wedding, and the one upsell nobody escapes.

> We got married in a drive-through chapel because my wife wanted something small, and the minister still upsold us on the extended warranty.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set). The line is validated before writing: 1–280 characters, a single line, no trailing newline, no control characters, not only whitespace.
